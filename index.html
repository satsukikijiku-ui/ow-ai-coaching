※本AIコーチングシステムはブロンズ〜エメラルドまでを対象に作っております。そのためダイヤモンド以降のランクでは、求めている結果は得られない可能性があります。
「攻撃/防衛」は、エスコート・ハイブリッド・フラッシュポイントなど攻守が分かれるモードで指定してください。動画だけでは攻撃側か防衛側かをAIが誤って判断することがあるため、指定しておくとコーチング内容の精度が上がります。コントロール・プッシュのように攻守が固定されないモードでは「該当なし」のままで問題ありません。
OWの「色覚設定」で敵/味方のハイライトカラーを標準(青=味方/赤=敵)から変更している場合は、ここで実際に使用している色を選んでください。動画内の壁やアビリティのエフェクトなどを敵/味方どちらのものか、AIが色で誤判定しないようにするために使用します。

API / モデル設定

このシステムはブラウザから直接 Google Gemini API を呼び出します。APIキーはこの端末のブラウザ内(localStorage)に平文で保存され、外部サーバーには送信されません。ご自身の Google AI Studio で発行したAPIキーを入力してください。

⚠ APIキーは暗号化されずにこのブラウザ内に保存されます。共有PC・共用端末で利用した場合は、使い終わったら下の「保存済みのAPIキーを削除」から必ず削除してください。またAPIキー自体が第三者に渡らないよう、スクリーンショットやURLの共有時にも映り込みにご注意ください。
「共有パソコン」を選ぶと、このページを閉じようとした際にAPIキーが削除されているか確認し、削除されていない場合は警告を表示します。
有効にすると、30分間このアプリの操作(クリック・キー入力など)がなかった場合、安全のためGemini・YouTube両方のAPIキーを自動的に削除します。
Google Cloud Consoleで「YouTube Data API v3」を有効化して発行したAPIキーです。設定すると、情報収集はGoogle検索全般ではなく実際のYouTube動画検索に固定され、関連度の高い上位動画(最大2本・各冒頭8分程度)はGeminiが実際に映像を視聴して解析し、それをもとに攻略情報をまとめます(動画が非公開等で読み込めない場合はタイトル・概要のみで代替します)。未設定の場合はAIの一般知識のみで攻略情報を作成します(Gemini側のWeb検索機能は使用しません)。
⚠ 動画解析にはGoogle Cloudの利用料が発生する場合があります。長い動画・広い分析範囲ほどトークン消費が増えます。ご自身の責任・利用規約の範囲でご利用ください。
Gemini APIの無料プランの目安上限(1分15リクエスト/1日1,500リクエスト/1分100万トークン)を超えないよう、このアプリはAPI呼び出しの間隔を自動的に調整しています。
YouTube Data APIにも別途無料枠(目安: 1日あたり検索100回程度)があります。使い切ると情報収集はAIの一般知識のみのフォールバックになります。

⚠ APIキーが残っています

APIキーの削除がされていません。安全性のため共有パソコンのAPIキーを削除してください。

使い方

  1. 右上の⚙から Gemini APIキーとモデルを設定します。
  2. 左側の「コーチング設定」で、ランク帯・マップ・デバイス・ロール・使用キャラを入力します。
  3. 右下のドロップゾーンからプレイ動画をアップロードします。
  4. 「読み込ませる範囲」で、AIに見てほしい区間(開始〜終了)をスライダーまたは直接入力で指定します。
  5. 「AIコーチング開始」を押すと、①設定内容をもとにAIがYouTube(YouTube Data APIキー未設定時はAIの一般知識)で最新の攻略情報を収集し、②指定範囲の動画を実際に解析して、タイムスタンプ付きのコーチング内容を左側に出力します。
  6. 出力後は下部の入力欄から追加質問ができます。
  7. 処理中に右上の「■ 中止」を押すと、AIコーチングの処理をその場で中断できます。
