# OW AI コーチングシステム

Overwatch 2のプレイ動画をアップロードすると、Google Gemini APIが動画を解析し、タイムスタンプ付きでAIコーチングを行うWebアプリです。サーバー不要の単一HTMLファイルで動作し、各利用者が自分のAPIキーを入力して使う仕組みになっています。

**本ツールはBlizzard Entertainment公式とは無関係の、個人が作成した非公式ファンメイドツールです。**

## できること

- 試合動画(mp4/mov/avi/mkv、最大2GB)をブラウザにアップロードし、指定した区間をGeminiが解析
- ランク帯・マップ・攻撃/防衛・デバイス・ロール・使用キャラなどの設定に応じたコーチング内容を生成
- YouTube Data APIキーを設定すると、実際の攻略動画を検索してAIが視聴したうえで最新情報を反映(未設定時はAIの一般知識のみで代替)
- コーチング結果に対する追加質問への回答

## 使い方

1. このリポジトリの `index.html` をブラウザで開く(GitHub Pagesで公開している場合は、そのURLにアクセスするだけでOK)。
2. 右上の⚙から、ご自身のGemini APIキー(必須)とYouTube Data APIキー(任意)を入力して保存する。
   - Gemini APIキーは [Google AI Studio](https://aistudio.google.com/apikey) から無料で発行できます。
   - YouTube Data APIキーは [Google Cloud Console](https://console.cloud.google.com/) でYouTube Data API v3を有効化して発行します。
   - 取得手順は⚙内の「Geminiキーの取得方法」「YouTubeキーの取得方法」ボタンから画像付きで確認できます。
3. コーチング設定(ランク帯・マップなど)を入力し、動画をアップロードして分析範囲を指定する。
4. 「AIコーチング開始」を押す。

## セキュリティ・プライバシーについて(重要)

- **APIキーの保存方法**: 入力したAPIキーは、この端末のブラウザ内(`localStorage`)に**平文で**保存され、外部サーバーには送信されません。暗号化はされていないため、共有PC・共用端末で利用した場合は、使い終わったら⚙の「保存済みのAPIキーを削除」ボタンから必ず削除してください。
- **依存ライブラリのバージョン固定**: Gemini SDK(`@google/genai`)はCDN(esm.sh)経由で読み込んでいますが、サプライチェーン攻撃対策としてバージョンを固定して読み込んでいます。ライブラリを更新する際は、必ず変更内容を確認したうえでバージョン番号を書き換えてください。
- **アップロード動画のプライバシー**: アップロードした動画は解析のためGoogleのGemini APIに送信されます。自分視点以外のプレイヤーの表示名・ボイスチャット・立ち回り等が映り込む動画の場合、本人の同意なくGoogleへ送信されることになります。可能であればリプレイ機能で撮影した自分視点のみの動画の利用を推奨します。
- **モデル一覧の保守**: 使用モデルの選択肢(`gemini-3.x-...`等)と廃止モデル一覧(`RETIRED_MODELS`)は手動管理です。Geminiのモデル世代は短期間で入れ替わるため、[公式のモデル一覧](https://ai.google.dev/gemini-api/docs/models)を定期的に確認し、新モデルの追加・廃止モデルの反映を行ってください。
